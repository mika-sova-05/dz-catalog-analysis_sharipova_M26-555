# Анализ каталога фильмов стримингового сервиса

Учебный Python-проект для анализа каталога фильмов с использованием базовых конструкций языка Python и встроенных структур данных.

## Описание проекта

Программа анализирует каталог фильмов, содержащий информацию о названиях, годах выпуска, жанрах, рейтингах, продолжительности и актёрах.

В проекте реализованы функции для расчёта статистики, классификации фильмов, сортировки, обработки коллекций и формирования итогового отчёта.

## Требования

- Python 3.12 или выше
- [uv](https://docs.astral.sh/uv/)

## Установка и запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/mika-sova-05/dz-catalog-analysis_sharipova_M26-555.git
```

Перейдите в папку проекта:

```bash
cd dz-catalog-analysis_sharipova_M26-555
```

Установите зависимости:

```bash
uv sync
```

Запустите программу:

```bash
uv run catalog_analysis.py
```

Проверка качества кода:

```bash
uv run ruff check .
```

## Реализованные этапы

1. **Переменные и числовые типы** — расчёт среднего рейтинга, возраста каталога и форматирование продолжительности фильмов.
2. **Условные конструкции** — классификация фильмов по рейтингу и году выпуска с использованием `if/elif`, тернарного оператора и `match/case`.
3. **Циклы** — обработка каталога с помощью `for`, `while`, `continue`, `break` и `else`.
4. **Строки** — нормализация названий, создание слагов и форматирование строк отчёта.
5. **Списки и сортировка** — сортировка фильмов по рейтингу и формирование топ-3.
6. **Словари** — подсчёт фильмов по жанрам, фильмография актёров и выборка фильмов с рейтингом выше среднего.
7. **Множества** — получение уникальных жанров, поиск общих актёров и сравнение наборов жанров.
8. **Генераторы** — генерация фильмов с высоким рейтингом и расчёт суммарной продолжительности.
9. **Итоговый отчёт** — объединение результатов анализа в единый консольный отчёт.
